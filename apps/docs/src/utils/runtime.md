# Runtime & Events

Runtime and event utility modules.

## Modules

| Module | Import Path | Description |
|--------|-------------|-------------|
| Events | `bf6-portal-utils/events` | Event system |
| Timers | `bf6-portal-utils/timers` | Timer utilities |
| Clocks | `bf6-portal-utils/clocks` | Clock management |
| Callback Handler | `bf6-portal-utils/callback-handler` | Callback management |
| Player Undeploy Fixer | `bf6-portal-utils/player-undeploy-fixer` | Fix player undeploy |
| Mod Extensions | `bf6-portal-utils/mod-extensions` | Mod extension utilities |

## Usage

```typescript
import { Timer } from 'bf6-portal-utils/timers';
import { EventEmitter } from 'bf6-portal-utils/events';
```
