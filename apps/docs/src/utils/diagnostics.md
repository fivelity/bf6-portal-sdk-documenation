# Diagnostics

Diagnostic and logging utility modules.

## Modules

| Module | Import Path | Description |
|--------|-------------|-------------|
| Logging | `bf6-portal-utils/logging` | Logging utilities |
| Logger | `bf6-portal-utils/logger` | Logger implementation |
| Performance Stats | `bf6-portal-utils/performance-stats` | Performance metrics |
| Benchmarker | `bf6-portal-utils/benchmarker` | Benchmarking tools |

## Usage

```typescript
import { Logger } from 'bf6-portal-utils/logging';
import { PerformanceStats } from 'bf6-portal-utils/performance-stats';
```
