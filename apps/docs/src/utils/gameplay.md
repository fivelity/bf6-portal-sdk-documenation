# Gameplay & World

Gameplay and world utility modules.

## Modules

| Module | Import Path | Description |
|--------|-------------|-------------|
| FFA Spawn Points | `bf6-portal-utils/ffa-spawn-points` | Free-for-all spawn points |
| FFA Drop Ins | `bf6-portal-utils/ffa-drop-ins` | Free-for-all drop-in mechanics |
| Scavenger Drop | `bf6-portal-utils/scavenger-drop` | Scavenger drop mechanics |
| Portal Gadget | `bf6-portal-utils/portal-gadget` | Portal gadget management |
| Raycast | `bf6-portal-utils/raycast` | Raycasting utilities |
| Multi-Click Detector | `bf6-portal-utils/multi-click-detector` | Multi-click detection |
| Sounds | `bf6-portal-utils/sounds` | Sound management |
| Map Detector | `bf6-portal-utils/map-detector` | Map detection |
| Vectors | `bf6-portal-utils/vectors` | Vector math utilities |

## Usage

```typescript
import { Vector } from 'bf6-portal-utils/vectors';
import { Raycast } from 'bf6-portal-utils/raycast';
```
