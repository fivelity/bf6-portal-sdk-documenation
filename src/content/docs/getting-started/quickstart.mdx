title: Quickstart
description: Write, type-check, and run a minimal Portal mode using mod, Events, and Logger.
---

import { Steps } from "@astrojs/starlight/components";

<Steps>

1. Install the packages, following [Installation](../installation/).

2. Subscribe to a Portal event through the Events module — not by exporting
   your own `On*` function directly.

   ```ts title="src/mode.ts"
   import { Events } from "bf6-portal-utils/events";

   Events.OnPlayerDeployed.subscribe((eventPlayer: mod.Player) => {
     mod.DisplayNotificationMessage(mod.Message("Welcome!"), eventPlayer);
   });
   ```

3. Add Logger while you're building, to see runtime values on screen.

   ```ts title="src/mode.ts"
   import { Events } from "bf6-portal-utils/events";
   import { Logger } from "bf6-portal-utils/logger";

   let debugLog: Logger | undefined;

   Events.OnPlayerDeployed.subscribe((eventPlayer: mod.Player) => {
     if (!debugLog) {
       debugLog = new Logger(eventPlayer, {
         staticRows: true,
         visible: true,
         anchor: mod.UIAnchor.TopLeft,
         width: 600,
       });
     }
     debugLog.log("Player deployed");
   });
   ```

4. Type-check.

   ```bash
   npx tsc --noEmit
   ```

5. Bundle with `bf6-portal-bundler` and upload the generated script and
   strings file through the Portal experience editor.

</Steps>

The compiler catches a mistyped `mod` call or a wrong Logger option before
you ever load a test match.
