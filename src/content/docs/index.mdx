## Ground truth, not tutorials

This site is generated directly from the installed `.d.ts` files with
[TypeDoc](https://typedoc.org/), not hand-copied from community guides. If a
symbol isn't in the reference, it isn't in the SDK — a distinction that matters,
since fabricated APIs (imagined `Network` or `Input` namespaces, a `player.GetPosition()`
that doesn't exist) circulate often enough in unofficial write-ups to trip up a build.
