`bf6-portal-mod-types` provides TypeScript declarations for the Battlefield
6 Portal `mod` namespace. It ships no runtime code — only `.d.ts` files.

## It is global, not imported

Once the package is listed in your `tsconfig.json`'s `compilerOptions.types`,
`mod` is available everywhere TypeScript compiles in your project. There is
nothing to import.

```ts
// Works with no import statement anywhere in the file.
const position = mod.GetSoldierState(player, mod.SoldierStateVector.GetPosition);
```

## Version numbering

The official Portal SDK uses a four-part version for `mod` (for example
`1.4.2.0`) that does not follow semver. This package maps that to a
three-part version by dropping the first segment: SDK `1.4.2.0` becomes
package `4.2.x`. A patch bump (`4.2.0` → `4.2.1`) means added documentation
only, with no change to the `mod` API surface; a minor bump means a new
official SDK release.

## What is inside

- **`mod.<Verb...>` functions** — the full runtime API: reading and setting
  soldier state, spawning objects, displaying UI and messages, and more.
- **Enums** — fixed value sets such as `mod.SoldierStateBool`,
  `mod.UIAnchor`, and team and vehicle classes.
- **Event handler signatures** — the exact parameter types for functions
  like `OnPlayerDeployed` that the Portal runtime calls.

:::tip

from its `.d.ts` source with full JSDoc:
