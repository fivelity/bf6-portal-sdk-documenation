## Reading player state

`mod` exposes player state through getter functions parameterized by an
enum, rather than plain object properties:

```ts
const isAlive = mod.GetSoldierState(player, mod.SoldierStateBool.IsAlive);
const position = mod.GetSoldierState(player, mod.SoldierStateVector.GetPosition);
```

## Working with teams

```ts
export function OnPlayerDeployed(eventPlayer: mod.Player): void {
  const team = mod.GetTeamId(eventPlayer);
  mod.DisplayNotificationMessage(mod.Message("Team: {}", team), eventPlayer);
}
```

## Modeling your own mode configuration

`mod` describes what the engine gives you. Model your mode's own settings
with a plain, typed interface so a misspelled key fails at compile time
rather than silently doing nothing at runtime:

```ts
interface ModeConfig {
  readonly roundLengthSeconds: number;
  readonly maxPlayers: number;
}

const config: ModeConfig = {
  roundLengthSeconds: 600,
  maxPlayers: 32,
};
```
