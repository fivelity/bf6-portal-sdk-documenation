Every named constant set shipped by the package — from input bindings
([`AiInput`](/reference/mod-types/bf6-portal-mod-types/namespaces/mod/enumerations/aiinput/):
`Crouch`, `FireWeapon`, `Jump`, …) to ammo and armor types
([`AmmoTypes`](/reference/mod-types/bf6-portal-mod-types/namespaces/mod/enumerations/ammotypes/),
[`ArmorTypes`](/reference/mod-types/bf6-portal-mod-types/namespaces/mod/enumerations/armortypes/))
and objective state
([`BombState`](/reference/mod-types/bf6-portal-mod-types/namespaces/mod/enumerations/bombstate/)).

Each enum page is an **Enumeration Members** table — member, value, and
the `.d.ts` line it is declared on — with an anchor per member, so you can
link straight to a single member from anywhere.

These types travel through function signatures and event arguments: see
[Functions](/reference/mod-types/bf6-portal-mod-types/namespaces/mod/functions/)
for the calls that consume them, and
[Event Handlers & Enums](/mod-types/events-and-enums/) for how enums fit
into the event system.
